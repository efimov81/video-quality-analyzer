# Пользователи и привязка заданий

Изучи существующие модели PostgreSQL, миграции, API создания заданий и запусков анализа.

Реализуй минимальную модель пользователей для будущих интеграций Web, Telegram и MCP.

## Требования

1. Создать таблицу `users`:
   - `id`
   - `display_name`
   - `is_active`
   - `created_at`
   - `updated_at`

2. Создать таблицу `external_identities`:
   - `id`
   - `user_id`
   - `provider` — строка (`web`, `telegram`, `mcp` и другие)
   - `external_user_id` — строка
   - уникальная пара `(provider, external_user_id)`.

3. Добавить в существующую модель задания поле `created_by_user_id`.

4. Добавить в модель запуска анализа поле `requested_by_user_id`, если анализ запускается отдельно от создания задания.

5. Для существующих данных предусмотреть корректную миграцию. Не удалять и не терять существующие задания и анализы. Для исторических записей допускается `NULL` в полях пользователя.

6. Добавить связи и индексы, необходимые для выборки заданий и анализов по пользователю.

7. Не изменять существующие алгоритмы анализа видео, профили проверок и логику очередей.

8. Не реализовывать авторизацию, регистрацию, пароли, JWT, Telegram или управление пользователями через UI.

9. При создании задания разрешать передавать source и externalUserId. Находить пользователя по паре (source, externalUserId) в external_identities, проверять is_active и сохранять внутренний user_id. Если пользователь отсутствует или неактивен — отклонять запрос. На текущем этапе идентификатор клиента считается доверенным; полноценную аутентификацию не реализовывать.

10. Обновить документацию модели данных и добавить тесты миграций и связей.

## Проверка

- Выполнить миграции.
- Запустить существующие тесты.
- Проверить, что старые API-вызовы продолжают работать.
- Убедиться, что существующие задания и результаты анализа сохранились.

В конце перечисли изменённые файлы, результаты тестов и возможные проблемы.

Не реализуй следующие задачи заранее. Ограничь изменения только моделью данных и необходимыми совместимыми изменениями API.
